Ты — Senior Backend Developer. Твоя задача: написать Telegram-бота для продажи подписок на MTProxy. 
В качестве прокси-сервера используется высокопроизводительный проект на Rust — `telemt` (https://github.com/telemt/telemt). 

АРХИТЕКТУРА И ЛОГИКА РАБОТЫ:
В отличие от панелей типа 3X-UI, в `telemt` нет встроенного биллинга и управления подписками. Сервер просто маршрутизирует трафик по ключам. Вся бизнес-логика ложится на бота:
1. Бот принимает оплату от юзера (можешь пока сделать мок-оплату или Stars/CryptoBot).
2. Бот генерирует новый MTProto-секрет для FakeTLS (формат: префикс `ee` + 32 символа hex случайного ключа + hex-кодированный домен для маскировки, например, google.com).
3. Бот делает HTTP-запрос к Control API V1 сервера `telemt`, чтобы добавить этот секрет "на лету" без перезагрузки прокси-сервера.
4. Бот сохраняет в базу данных (SQLite/PostgreSQL) связку: Telegram_ID, выданный Secret и дату окончания подписки (Expires_At).
5. Бот пересылает юзеру готовую ссылку: tg://proxy?server=<IP>&port=<PORT>&secret=<SECRET>
6. В боте в фоне крутится планировщик (например, APScheduler). Раз в 5 минут он ищет в БД подписки, у которых наступил Expires_At. Если находит — делает HTTP-запрос в Control API `telemt` на удаление этого секрета и помечает подписку в БД как неактивную.

ШАГ 1: ИЗУЧЕНИЕ ИНФРАСТРУКТУРЫ TELEMT
Прежде чем писать код бота, тебе нужно понять, как работает API `telemt`. 
1. Склонируй репозиторий: `git clone https://github.com/telemt/telemt.git` в отдельную временную папку.
2. Изучи файл `config.full.toml` в корне репозитория. Найди там секцию, отвечающую за Control API (HTTP API), метрики и управление юзерами.
3. Изучи исходный код обработки API (вероятно, папка `src/api`, `src/control` или обработчики HTTP). Найди точные маршруты (endpoints) и структуру JSON для:
   - Добавления нового секрета (пользователя).
   - Удаления секрета.
   - (Опционально) Получения статистики трафика по секрету.
4. Составь для меня (как для админа) краткую инструкцию: как мне настроить `config.toml` в `telemt`, чтобы бот мог безопасно по локальной сети управлять ключами через API.

ШАГ 2: НАПИСАНИЕ БОТА
Напиши код Telegram-бота на Python (используй aiogram 3.x и aiosqlite/SQLAlchemy) или Node.js (Telegraf + Prisma/SQLite) — выбери то, что посчитаешь более стабильным.

Должны быть реализованы следующие модули:
1. Database: Таблицы Users и Subscriptions.
2. Proxy Manager: Класс/модуль, реализующий методы `add_secret(secret)` и `remove_secret(secret)`, делающие REST HTTP запросы к API локально запущенного `telemt`. Не забудь про обработку заголовков авторизации (если они требуются в конфиге telemt).
3. Secret Generator: Функция, генерирующая валидный ee-секрет для Telegram (FakeTLS).
4. Handlers: 
   - /start (Главное меню с инлайн кнопками: "Купить прокси", "Мои прокси").
   - Логика выдачи прокси после нажатия "Купить".
5. Background Worker: Фоновая задача, которая проверяет истекшие ключи, удаляет их из `telemt` и отправляет юзеру сообщение об отключении.
